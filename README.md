# 釋疑單 PDF → 彙整總表 Excel

把用 Canva 製作的釋疑單（RFI）問題紀錄 PDF，自動轉成彙整總表 Excel。

**線上使用：** https://wsl0407.github.io/Request-for-Information/

所有處理都在瀏覽器中完成，PDF 與 Excel 不會上傳到任何伺服器；也可以下載 `index.html` 離線使用。

## 使用方式

1. **加入 PDF**：點選或拖曳，可多份、可分次加入
2. **匯出設定**（可留空）：RFI 檔案編號、發文日期、是否接在範本現有資料後面
   - 按「更換範本…」選擇你自己的總表 xlsx（內建的是空白範本）
3. **預覽**：點儲存格可直接修改，× 刪除該列；紅底表示缺少圖號或問題內容
4. **匯出 Excel**

## PDF 製作規則

- **分類頁**：整頁只放分類標題（例：地上層-實驗棟 / 輕隔間）→ Excel 分組標題列
- **問題頁**：左側文字欄依序放以下標籤
  - `圖說編號名稱:` 圖號一行、圖名一行，可多組
  - `位置:` 第一行只寫樓層（一樓／十樓、十一樓／多個樓層）會進樓層欄，其餘進位置欄
  - `問題:` 分點用「1.」「2.」開頭；「圖說確認-」會自動略過；以「已提出」開頭的行會填入已提出欄，後面文字進釋疑單位回覆
  - `建議:` 不會填入 Excel
- 圖片上的標註文字放在文字欄右側，程式會自動忽略
- 最後一頁只寫 `END`
- PDF 必須可選取文字（Canva 匯出即可；掃描或整頁截圖無法讀取）

## 範本需求

自訂範本需有工作表「追蹤用(建築)」，第 3 列為表頭，第 4 列為分組標題列格式，第 5 列為問題列格式。

使用 [pdf.js](https://github.com/mozilla/pdf.js) 與 [ExcelJS](https://github.com/exceljs/exceljs)，皆已內嵌於 `index.html`。
